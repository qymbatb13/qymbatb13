## 📱 Проекты

### [EventSpot](https://github.com/qymbatb13/eventspot1)
Приложение для поиска мероприятий на интерактивной карте.
- Кластеризация меток (собственный алгоритм), фильтры по категориям, геопозиция
- Вход и регистрация, светлая и тёмная темы
- Feature-First Clean Architecture, BLoC, тесты
- `Flutter` `BLoC` `Clean Architecture` `REST API`

### [QuickJob](https://github.com/qymbatb13/QuickJob)
Маркетплейс микроподработок для школьников и студентов (MVP).
- Две роли: исполнитель и работодатель
- Полный цикл: задание → отклик → выбор исполнителя → оплата → отзыв
- Каталог с поиском и фильтрами, профили с рейтингом
- `Flutter` `Dart` `ChangeNotifier`

### [Road Racer](https://github.com/qymbatb13/road-racer)
Это бесконечная гоночная игра, где ты мчишься по трассе, уворачиваясь от трафика и собирая монеты. Используй нитро для ускорения, покупай новые машины в гараже и бей собственные рекорды!
- `Flutter` `Dart`
